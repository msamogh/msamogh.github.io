My attention leaks in specific, repeatable ways: a feed that eats an hour, a code that pulls me into an inbox, a day that ends with nothing to show. Each tool here plugs one of those leaks. I build them with coding agents in an evening or a weekend, shape them to exactly one person, and keep using the ones that earn it.

They all launch from Workbench, a native SwiftUI launcher. One apps.json manifest feeds the launcher, its icons, and this page. ⌃⌥Space summons it, typing filters it, ↩ opens.

How they're built

Rules I keep coming back to

01

Make the bad path impossible, not just costly.

Ratchet won't let work start without a goal. Sieve never paints a raw post. Willpower is a bad dependency.

02

Local first, private by default.

Money, codes and feeds stay on the Mac. Model calls go through a locked-down CLI with no tools when the input is untrusted.

03

Built for one person.

No onboarding, no settings nobody uses. Each tool fits exactly one person's habits, which is why each one is small.

04

Agents write the code; I own the taste.

Coding agents write the code. My job is the spec, the corrections, and deciding what to throw away.
